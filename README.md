# Fuel Freely – Master UI/UX Prompt Repository

This repository contains the master prompt specification split into four parts:

- Part_1A.md
- Part_1B.md
- Part_2.md

## Target Stack

Frontend Deployment: Netlify

Backend: Firebase
- Firebase Authentication
- Firestore
- Firebase Cloud Messaging

Nutrition API:
- USDA FoodData Central API

Translation:
- LibreTranslate API

The prompt is intended to drive the complete design and implementation of the Fuel Freely responsive web application.
