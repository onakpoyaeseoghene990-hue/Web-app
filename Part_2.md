# Fuel Freely Master UI/UX Prompt - Part 2
==================================================
MASTER UI/UX PROMPT — PART 2
Fuel Freely (Responsive AI-Powered Nutrition Web Application)
==================================================

--------------------------------------------------

NUTRITIONIST CONNECTION

Provide a secure Nutritionist Portal that enables collaboration between users and registered nutritionists while ensuring users maintain full control over their personal information.

The nutritionist experience should be integrated into the main application and protected by role-based access control.

--------------------------------------------------

USER–NUTRITIONIST LINKING

Allow users to connect with a nutritionist through one of the following methods.

• Invitation Code

• Email Invitation

• Secure Link

The user must explicitly approve every connection request before access is granted.

Users can disconnect a nutritionist at any time.

Display a confirmation dialog before connecting or disconnecting a nutritionist.

--------------------------------------------------

ROLE-BASED ACCESS

Implement separate dashboards for

• Standard Users

• Nutritionists

Nutritionists should only access information that users have explicitly shared.

Never grant unrestricted access by default.

--------------------------------------------------

NUTRITIONIST DASHBOARD

Display

• Assigned Clients

• Client Progress Overview

• Recent Meal Logs

• Nutrition Trends

• Pending Client Messages

• Recent Recommendations

Allow sorting and filtering by

• Name

• Progress

• Goal

• Last Activity

--------------------------------------------------

CLIENT PROFILE

When viewing a client, display

• Profile Summary

• Nutrition Goals

• Meal History

• Daily Nutrition Summary

• Weekly Progress

• Weight Trend

• Allergies

• Food Intolerances

• Dietary Requirements

Display only information the client has chosen to share.

--------------------------------------------------

MEAL-SPECIFIC FEEDBACK

Nutritionists can attach guidance directly to a logged meal.

Each recommendation should remain linked to that meal.

Examples

"This meal is well balanced."

"Consider replacing fried plantain with boiled plantain."

"Increase your vegetable portion."

Users should easily distinguish meal-specific advice from general recommendations.

--------------------------------------------------

GENERAL NUTRITION GUIDANCE

Allow nutritionists to send

• Educational messages

• Weekly recommendations

• Progress reviews

• Motivation

Messages should appear in the user's Notifications and Nutritionist sections.

--------------------------------------------------

PRIVACY CONTROLS

Allow users to decide exactly what information is shared.

Options

□ Meal History

□ Nutrition Progress

□ Weight History

□ Allergies

□ Food Intolerances

□ Dietary Requirements

□ Water Intake

□ Activity Summary

Changes should take effect immediately.

Display confirmation before saving privacy changes.

--------------------------------------------------

DIETARY REQUIREMENTS

Allow users to personalize nutrition according to their lifestyle, medical needs, and personal preferences.

Support multiple selections.

Examples

• Vegetarian

• Vegan

• Halal

• Kosher

• Gluten-Free

• Lactose-Free

• Diabetic-Friendly

• Low Sodium

• High Protein

• Pregnancy-Friendly

• Religious Fasting

• Other

Selected preferences should automatically influence

• Meal Recommendations

• Nutritional Targets

• AI Meal Suggestions

• Food Alternatives

• Nutrition Insights

Allow users to edit dietary preferences from their profile at any time.

--------------------------------------------------

ALLERGY MANAGEMENT

Allow users to record

• Food Allergies

• Food Intolerances

Assign severity levels to allergies.

Examples

• Mild

• Moderate

• Severe

Visually distinguish

High-Risk Allergies

from

Food Intolerances

using different icons, colours, and badges.

Whenever allergens are detected in a meal

Display

• Detected Allergen

• Severity Level

• Reason for Detection

Immediately recommend safer alternatives.

Examples

Instead of

Peanut Soup

Suggest

Egusi Soup

Instead of

Cow Milk

Suggest

Soy Milk

Instead of

White Bread

Suggest

Gluten-Free Bread

Alternative meals should always consider

• Remaining Calories

• Macronutrient Targets

• Dietary Requirements

• Preferred Cuisine

• Allergy Profile

--------------------------------------------------

DISCLAIMERS

Display important health information throughout the application instead of hiding it within legal documents.

Whenever nutritional information is displayed

Clearly indicate

"Calorie values are estimates and may vary depending on preparation method and serving size."

Whenever allergens are detected

Display

"Allergen detection provides guidance only and should not replace professional medical advice."

For users with severe allergies

Require a one-time acknowledgement.

Example

"I understand that Fuel Freely is an educational nutrition platform and does not replace advice from my healthcare professional."

Store the acknowledgement within the user's account.

--------------------------------------------------

POST-MEAL REVIEW

After every confirmed meal

Display a comprehensive nutritional review.

Include

• Updated Calories

• Remaining Calories

• Macronutrient Breakdown

• Daily Progress

• Weekly Progress

Provide contextual recommendations based on the user's overall nutritional pattern rather than judging a single meal.

Examples

• Increase your protein intake during dinner.

• Include more vegetables later today.

• Drink another glass of water.

• Reduce sugary snacks tomorrow.

Suggestions should always remain realistic and culturally appropriate.

Examples

Instead of

"Eat grilled salmon."

Suggest

"Add beans to your rice."

or

"Include moi-moi with lunch."

--------------------------------------------------

NUTRITION INSIGHTS

Generate intelligent summaries using historical nutrition data.

Examples

• Your fibre intake has improved this week.

• You consistently exceed your sodium target on weekends.

• Your protein intake is below your recommended target.

Present trends using

• Weekly Charts

• Monthly Charts

• Progress Cards

Keep all feedback constructive and encouraging.

--------------------------------------------------

RESPONSIBLE DESIGN

Provide a Simplified View that users can enable from Settings.

When enabled

Replace detailed numbers with meaningful guidance.

Examples

Instead of

1,860 kcal

Display

"On Track"

Instead of

Protein 58 g

Display

"Protein Goal Nearly Reached"

Instead of

Fat 91 g

Display

"Choose Lighter Meals Later Today"

Avoid red warning colours whenever possible.

Use calm, neutral colours and supportive language.

Examples

Instead of

"You exceeded today's calorie goal."

Display

"You've eaten more than planned today. Focus on balanced choices during your next meal."

The application should encourage sustainable healthy habits rather than guilt or obsessive calorie tracking.

--------------------------------------------------

SETTINGS

Allow users to manage

• Profile Information

• Password

• Preferred Language

• Cuisine Preference

• Dietary Requirements

• Allergies

• Notification Preferences

• Simplified View

• Connected Nutritionist

• Privacy Settings

Every change should be confirmed before being saved.

--------------------------------------------------
