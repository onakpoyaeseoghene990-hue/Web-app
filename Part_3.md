--------------------------------------------------

ACCESSIBILITY

Comply with WCAG 2.2 AA standards.

Include

• High Colour Contrast

• Screen Reader Support

• Keyboard Navigation

• Focus Indicators

• Accessible Labels

• Minimum Interactive Target Sizes

• Dynamic Text Scaling

• Colour-Independent Status Indicators

• Plain Language

Never communicate status using colour alone.

--------------------------------------------------

PERFORMANCE

Design for fast loading and smooth interaction.

Prioritize

• Lazy Loading where appropriate

• Optimized Images

• Efficient API Requests

• Responsive Tables

• Pagination for Large Datasets

• Client-Side Caching where appropriate

Minimize unnecessary network requests and visual layout shifts.
